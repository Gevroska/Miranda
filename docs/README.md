# Miranda documentation

| Area | Purpose |
|---|---|
| [Planning](planning/README.md) | Scope, decisions, source comparisons and acceptance requirements. |
| [Development](development/README.md) | Contribution workflow, architecture records, validation and releases. |
| [Status](development/STATUS.md) | Actual implementation and delivery evidence. |

Each area has one responsibility. Planning documents describe required behavior; status entries describe what has been implemented and verified. Release notes describe a published package, not the entire roadmap.
